# Documentação de `@jeftelabs/prompts`

`@jeftelabs/prompts` encapsula prompts de terminal do Enquirer e permite substituir interações por respostas programáticas em testes. O [README raiz](../README.md) apresenta instalação, uso e API em poucas linhas.

- [Desenvolvimento](guides/development.md): estrutura, comandos e requisitos do runner/build.
